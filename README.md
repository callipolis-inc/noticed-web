# noticed-web

Official web application and editorial landing sanctuary for **Noticed** — for things you don't want to forget.

A quiet, offline-first personal & shared field notebook with Penguin Classics editorial typography and luxury digital archives.

## Stack
- Next.js 15 (Turbopack, App Router)
- React 19 + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons
